## Usage notes

- Use the two-color green + charcoal mark as the default.
- Use one-color charcoal for print, embossing, foil, stamps, or embroidery constraints.
- Use the reverse square when placing the logo on dark backgrounds.
- Use rust for CTAs and blocking states, not as the default logo color.
- For favicons, use the square icon PNG exports or the square SVG.
